WEBSITE EKSTRAKURIKULER SMKN 1 SUDIMORO

File:
- index.html      = halaman utama
- pramuka.html    = halaman Pramuka
- pmr.html        = halaman PMR
- osis.html       = halaman OSIS
- style.css       = seluruh desain
- script.js       = animasi/interaksi menu
- images/logo-smk.png = logo SMK yang diberikan

Cara menjalankan:
1. Ekstrak ZIP.
2. Buka index.html di browser.
3. Pastikan file HTML, style.css, script.js, dan folder images tetap berada dalam struktur yang sama.

Catatan:
Logo SMK menggunakan gambar yang diberikan. Logo organisasi saat ini dibuat sebagai badge teks (PR/PMR/OSIS) agar website langsung bisa berjalan.
Jika mempunyai logo resmi Pramuka, PMR, dan OSIS, ganti badge tersebut dengan file logo resmi.
